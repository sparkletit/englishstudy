📖 音节划分器

输入单词 · 元音标红 · 点击划分 · 点音标听发音

输入单词后按「显示」，再点击单词自动划分音节
划分口诀与规则（依据《音节划分与重音位置》）
1️⃣ 一个元音一音节：先数元音（元音组合算一个），词尾不发音的 e 不算；
2️⃣ 一靠后：两元音间 1 个辅音，归后一音节，如 stu-dent、o-pen；
3️⃣ 二分手：两元音间 2 个辅音，一边一个，如 let-ter、win-ter；
4️⃣ 组合不拆：th、sh、ch、ck、tch、ph 及辅音连缀保持完整；
5️⃣ 辅音 + le：-ble / -tle / -ple 自成一个音节，如 ta-ble、lit-tle；
6️⃣ 重音：单音节词本身重读；双音节多重读在前；多音节一般重读倒数第三；-tion、-ic 等后缀按后缀规则。
音标为英式 DJ 音标，按拼读规则生成，个别不规则词可能存在偏差。
元音 红色 · 灰色为不发音字母 · ˈ 重音符号
点音节卡播放整个音节 · 点单个音标只听该音素
音节/音素发音均为华为云 SIS 合成 · 整词朗读走有道在线发音

⚙ 语音设置

注册：elevenlabs.io 邮箱注册（免费，无需信用卡）→ 右上角头像 → Profile + API key → 复制 Key。支持 IPA 音标合成。注意免费层每月约 1 万字符且 SSML 标记计入（约 150 个新音节/月，本应用会缓存）；付费 $5/月起近乎不限。

已用华为云 SIS 为词表内 352 个音节批量生成标准读音（音色：Alvin 英文男声，音量 80），保存在 assets/syllables/ 文件夹，点音节直接播本地文件。遇到库里没有的音节（如生词），会自动通过本机 server.js 实时调 SIS 合成并缓存，之后同样秒播。要批量补充新词，在电脑上运行 gen-syllables.js（用法见脚本顶部注释）。注意：本页面需由 node server.js 启动访问，在线补齐功能才可用。

在 azure.microsoft.com 免费注册「语音服务」(F0 免费层每月 50 万字符)，创建资源时选择区域（如 eastasia / southeastasia / eastus），在「密钥和终结点」页复制 Key。
